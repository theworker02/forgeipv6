# forgeipv6

Forge HTML/Markdown ipv6 fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/forgeipv6/

## Install / run

```bash
git clone https://github.com/theworker02/forgeipv6.git
cd forgeipv6
node src/cli.js
node --test
```
